## Лабораторная работа №2: Камера и освещение

Выполнено базовое задание и дополнительные задания 1–3.

Базовое задание:
- свободная камера: позиция, поворот (yaw, pitch) и угол обзора задаются в интерфейсе,
  а также клавишами WASD / Q E и правой кнопкой мыши. Матрица вида строится как
  обратная к матрице камеры: `V = Rx(−pitch) · Ry(−yaw) · T(−position)`;
- у вершин есть атрибут нормали, нормали цилиндра генерируются процедурно
  (у дна и крышки — ±Y, у стенки — от оси наружу);
- освещение по модели Блинна-Фонга во фрагментном шейдере: направленный источник
  и рассеянный свет (ambient), все параметры изменяются в ImGui;
- параметры материала каждого объекта: альбедо, цвет блика, коэффициент блеска.

Дополнительные задания:
1. Внешние данные разделены на два набора дескрипторов: `set = 0` — сцена
   (uniform-буфер с матрицами вида и проекции, позицией камеры, ambient и направленным
   источником; два storage-буфера с массивами источников), `set = 1` — модель
   (матрица модели и материал).
2. Массив точечных источников в storage-буфере, затухание по закону обратных квадратов,
   добавление и удаление источников в интерфейсе.
3. Массив прожекторов в storage-буфере, затухание по закону обратных квадратов,
   мягкий край между внутренним и внешним углом, добавление и удаление в интерфейсе.

Storage-буферы растут автоматически (вдвое), когда источников становится больше,
чем в них помещается, поэтому в шейдере размер массивов не задаётся.

На сцене два цилиндра и пол: обе фигуры лежат в общих вершинном и индексном буферах.

## Лабораторная работа №1: Основы 3D-графики

Цилиндр из 50 вершин и 288 индексов, переключение проекций, преобразования,
анимация по траектории, цвет фигуры и процедурные цвета вершин, два объекта
со своими наборами дескрипторов. Код — тег `lab1`.

## Сборка

Нужны компилятор C++20, CMake ≥ 3.20 и Vulkan SDK (заголовки, loader и `glslc` в `PATH`).
На macOS подойдёт Vulkan SDK от LunarG.

```bash
cmake --preset debug
cmake --build build-debug --parallel
```

## Запуск

Запускать нужно из корня проекта, потому что шейдеры загружаются по относительному пути `shaders/*.spv`:

```bash
./build-debug/vulkan-starter-app
```
