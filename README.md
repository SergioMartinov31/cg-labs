# Лабораторная работа №1: Основы 3D-графики (Vulkan)

**Вариант 8: цилиндр (~50 вершин в основаниях).**
Номер в списке группы P = 20, количество вариантов N = 12, вариант = ((20 − 1) % 12) + 1 = 8.

Проект основан на [vulkan-starter-app](https://github.com/vladeemerr/vulkan-starter-app).
Код лабораторной находится в `source/application.cpp`, `source/math.hpp`
и `shaders/cylinder.{vert,frag}`.

## Что сделано

Основное задание: цилиндр строится процедурно из 50 вершин (по 25 в каждом основании:
центр и 24 точки на окружности) и 288 индексов (96 треугольников). Он рисуется
через вершинный и индексный буферы, а матрицы передаются в шейдер через uniform-буфер.

Дополнительные задания:

1. В интерфейсе можно переключать проекцию: перспективную или ортографическую.
2. Позиция, поворот и растяжение фигуры задаются через `DragFloat3`.
3. Анимация движения по траектории «восьмёрка» (кривая Лиссажу) с вращением вокруг своей оси.
   Есть кнопки Play/Pause и Restart, настраиваются скорость, радиус и высота траектории, скорость вращения.
4. Цвет фигуры выбирается через `ImGui::ColorEdit3`.
5. Цвет каждой вершины задаётся процедурно из её локальной позиции (`rgb = pos * 0.5 + 0.5`).
   Цвет из интерфейса умножается на цвет вершины.
6. На сцене два цилиндра. У каждого свой uniform-буфер и свой `VkDescriptorSet`.
   Геометрия общая: перед каждым `vkCmdDrawIndexed` привязывается нужный набор дескрипторов.

## Сборка

Нужны компилятор C++20, CMake ≥ 3.20 и Vulkan SDK (заголовки, loader и `glslc` в `PATH`).
На macOS подойдёт Vulkan SDK от LunarG или пакеты Homebrew
(`vulkan-headers vulkan-loader molten-vk shaderc`).

```bash
cmake --preset debug
cmake --build build-debug --parallel
```

## Запуск

Запускать нужно из корня проекта, потому что шейдеры загружаются по относительному пути `shaders/*.spv`:

```bash
./build-debug/vulkan-starter-app
```
